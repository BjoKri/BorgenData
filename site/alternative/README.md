# Designutkast (ikke publisert)

Disse versjonene lastes **ikke** opp ved deploy (`npm run deploy`).

- `v1/` – første redesign (flersidig PHP)
- `v2/` – enkeltside-prototype (alternativ2)
- `v3/` – arkivkopi av design som ble valgt til produksjon (se `site/index.php`)

Forhåndsvis lokalt:

- `npm run preview:alternative` → v1
- `npm run preview:alternative3` → v3
